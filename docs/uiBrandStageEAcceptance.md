## 已核对

### 主题和重点色

- 在外观设置页逐一切换 `neutral`、`blue`、`sage`（界面显示 Teal）、`amber`、`rose`，核对浅色和深色下的 `--primary`、`--primary-foreground`、`--ring` 与辅助色 token。
- 按各方案的 HSL 主色/前景色计算文字对比度。浅色 Amber 原为 3.98:1，低于 4.5:1；将主色和色板由 36% 调深至 33% 后为 4.62:1。其余浅色方案最低 6.02:1，深色方案最低 6.33:1。
- 重点色、深色主题和中文偏好均在页面刷新后恢复；验收结束时恢复为验收前的浅色、英文、Amber 设置。
- 首屏脚本、无效重点色回退和 `localStorage` 读写失败回退按 `index.html` 与 `src/lib/accentColor.ts` 实现审阅；未人为禁用浏览器存储。
- 长回复在聊天中可读；390px 下 composer 为单层边框、无投影，控件仍在视口内。

### 样式、资源和清理

- 常规卡片与 composer 使用无阴影样式；菜单、Sheet 等真正悬浮的层保留轻量层次。普通焦点样式使用当前重点色 token。
- 删除未被引用的 Vite 样板文件 `src/App.css`、`src/index.css`；源代码和入口中未发现这两个文件的引用。
- Shadcn Dashboard 作为布局和样式参考使用；未发现直接复制其模板页面、Logo 或演示资源。项目内 Geist 字体保留随附的 `public/fonts/geistOfl.txt` 许可文件。

### AG Grid 控制台错误

业务表格页最初报告缺少 `LocaleModule`（`localeText`）和 `TooltipModule`（`tooltipValueGetter`）。已将二者加入该表格的 `AgGridProvider` 模块列表；代码热更新后重新打开表格，未再出现该错误。AG Grid 要求在创建表格前注册所用功能模块，详见[官方模块文档](https://www.ag-grid.com/react-data-grid/modules/)。
