## 代表性桌面视觉记录

在隔离的本地浏览器标签页以 `1280 × 720` 检查了迁移前登录页（前端 commit `1d2be8a`）和 Shadcn Dashboard 模板首页（模板 commit `6f99c0b04b7169f9ef12dc99946bc4faaeb40b9b`）。两张图像由浏览器工具显示在任务记录中；当前工具只返回内联截图，无法把截图二进制写入仓库，因此本文件记录观察结果，不伪造仓库截图路径。

| 页面 | 迁移前 / 参考观察 |
| --- | --- |
| Asianode `/login` | 暗色中性背景；左侧品牌和登录表单，宽屏右侧为预览区域；表单宽度受限，输入和主操作纵向排列。登录态错误、浅色主题与窄屏截图未记录。 |
| Shadcn Dashboard `/` | 暗色后台工作台；左侧分组导航，中间顶部栏含搜索和账户操作；主区由标题、更新时间提示、图表、指标卡片和表格组成。边框和分割线细，控件紧凑，强调色集中用于状态/趋势。 |

模板桌面检查视口为 1280 × 720。模板可见首页默认深色展示；未在该次基线记录中保存切换后的浅色截图。两项视图仅作布局和视觉层级参考，不复用模板示例中的人员、销售或项目数据。

## 目标视口和主题矩阵

下列尺寸是后续人工验收的固定取样点；它们不是本轮已捕获的截图清单。

| 视口 | 取样尺寸 | 重点 |
| --- | --- | --- |
| 桌面 | `1440 × 900` | 侧栏展开/收起、页面内容区、聊天与 Artifact 分屏、表格列宽 |
| 平板 | `1024 × 768` | 侧栏收缩、筛选/操作换行、双栏到单栏过渡 |
| 手机 | `390 × 844` | 抽屉导航、表单可用宽度、聊天输入和 Artifact 覆盖布局、安全区与横向溢出 |

三个视口都应检查浅色、深色主题。聊天主界面还需检查流式中、停止/重试、附件和错误态；Artifact 需检查打开、编辑、保存、版本切换和失败反馈。设置、上传和表格页面需检查加载、空数据、失败、成功反馈及无权限状态。

| 路由 | 页面/布局归属 | 权限或路由状态 | 需纳入截图/人工查看的状态 |
| --- | --- | --- | --- |
| `/` | 新建聊天，应用侧栏与顶部栏 | 已登录；无需额外业务权限 | 空白新对话、模型/输入、附件、发送中、流式中、错误、手机输入区 |

| `/settings/knowledge-bases` | 知识库工作区 | `knowledge.manage` | 加载、列表/空、创建或选择、失败/拒绝 |

## 跨路由状态验收矩阵

| 状态 | 适用范围 | 检查点 |
| --- | --- | --- |
| 认证加载 / 未登录 | 所有受保护路由 | 加载提示；已知路由跳到登录；未知路由显示 404 |
| 授权加载 / 请求失败 | 应用 shell 与受保护业务页 | 权限加载反馈、重试动作、不会误展示受限页面 |
| 无权限 | 成员、知识库、上传、业务数据 | 友好拒绝态；导航入口可见性与后端权限一致 |
| 加载 / 空 / 失败 / 成功 | 设置、知识库、上传、表格、诊断页 | 骨架/进度、清晰空态、错误可读、mutation 有结果反馈 |
| 弹窗 / 菜单 / Tooltip | 导航、成员、知识库及操作区 | 焦点、键盘操作、遮挡和移动端定位 |
| 浅色 / 深色 | 所有页面 | 文字/边框对比、状态色、图表、表格和弹层适配 |
| 桌面 / 平板 / 手机 | 所有页面 | 侧栏折叠或抽屉、单列布局、无意外横向滚动 |
| SSE / Artifact 状态 | 聊天 `/`、`/chat/:id` | 等待、增量渲染、停止/错误；Artifact 打开、编辑、保存、版本与失败 |

## 当前证据边界

- 路由归属来自 `src/App.jsx` 的静态路由配置；状态清单结合各页面职责和认证/权限守卫整理，并不代表本轮逐条触发过所有后端状态。
- 可复核的本轮视觉取样仅为迁移前登录页和参考模板深色桌面首页，二者截图显示在任务浏览器记录中，没有保存到仓库。
- 没有拍摄或模拟每个权限角色的业务数据；没有对真实 workspace 执行聊天发送、文件上传、成员变更或 Artifact 保存。
- 阶段 3 和阶段 4 的后续人工核对限制见迁移计划顶部记录；阶段 5–7 应按本表逐页补充浅/深色、三个视口及关键状态的截图或录屏证据。
